## 关于第 9 章的数字

每个指标都标了**评测轮次与代码基线**。不同轮次的数据集规模不同，同一指标因此有两个都真实的
取值（例如 MS MARCO 的 Recall@5 在 n=98 那轮是 0.8878，在 n=150 那轮是 0.8707）。
**不要跨轮次横比**；没有特别说明时，以标注「2026-09-15」的那一轮为准。
